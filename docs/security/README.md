# Security advisory packets

> Canonical public route after an advisory is published:
> `https://docs.protocolsoup.com/developers/security-advisories/`

This directory holds **maintainer packets** used to fill GitHub repository
advisories and request CVEs. GitHub is ProtocolSoup's CVE Numbering Authority
(CNA): the GHSA description is what GitHub's security team copies into the CVE
record.
